Weekly review of the Dream Coherence canon.

1. `git checkout main && git pull`.
2. Run `bash tools/canon_audit.sh`.
3. List commits merged in the last 7 days.
4. Draft updates to CURRENT_STATE.md and NEXT_STEPS.md from those commits and DECISION_LOG. Show the drafts and wait for my approval.
5. From the OPEN decisions, recommend one to rule this week. Give options (a / b / s), the strongest counterargument, and your recommendation with confidence.
6. After I approve: branch `weekly/YYYY-MM-DD`, commit, push, give me the pull request link.
7. Close the weekly-review GitHub issue for this week if one is open (give me its link if you cannot close it).
8. Remind me: after merging, click "Sync now" in the Claude Project.
