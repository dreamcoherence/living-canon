# GitHub Workflow

## What GitHub does

GitHub is long-term memory and version control.

It gives Dream Coherence:

- one source of truth,
- history of every change,
- rollback,
- comparison between versions,
- branches for experiments,
- releases for stable versions,
- a durable project brain that survives chat sessions.

## Simple workflow

1. Create private repo: `dream-coherence-living-canon`.
2. Upload this repository.
3. Commit as `v2.0.0 fortified reboot`.
4. Add repo files to Claude Project.
5. Use Claude as daily operator.
6. Commit significant updates.
7. Tag major releases.

## Commit rhythm

Commit after:

- daily major work,
- new canonical file,
- launch asset completion,
- product change,
- strategy change,
- current state update.

## Branches

Use branches for experiments:

- `website-v2`
- `first-threshold-curriculum`
- `launch-emails`
- `founding-document`

Merge only when stable.

## Practical value

Without GitHub, the project fragments into chats.

With GitHub, every AI reads the same current organism.
