# ChatGPT Review Protocol

## Purpose

ChatGPT acts as external strategist, editor, pressure tester, and high-level architect.

Claude is the daily builder.

GitHub is the memory.

ChatGPT enters when pointed at specific files or packages.

## Best use cases

- Audit current strategy.
- Pressure-test launch plan.
- Improve voice.
- Synthesize multiple files.
- Generate repository patches.
- Review sales/funnel architecture.
- Check whether V2 lost V1 material.

## Best prompt

```
Review these Dream Coherence repository files as external strategist/editor:

[paste files or upload ZIP]

Assess:
1. coherence
2. omissions
3. voice quality
4. strategic leverage
5. commercial clarity
6. launch readiness
7. what should be updated

Then output exact patch text.
```

## Rule

Do not ask ChatGPT vague questions without files.

Point ChatGPT at exact materials.
